## 翻訳機能

OverTranslate には 5 つの翻訳機能があり、その場に合ったものをすぐ選べます。

- **[キャプチャ翻訳](#キャプチャ翻訳)** — 画面の範囲を選ぶと、文字を読み取って訳文をその場に重ねて表示します
- **[リアルタイム翻訳](#リアルタイム翻訳)** — 動画・ゲーム・マンガの範囲を選ぶと、文字を読み取り続けて訳文をその場に重ねて表示します
- **[ポップアップ翻訳](#ポップアップ翻訳)** — テキストを選ぶと小さな翻訳ウィンドウが開きます。ピン留めして出したままにもできます
- **[置換翻訳](#置換翻訳)** — テキストを選んでショートカットキーを押すと、その場で訳文に置き換わります
- **[テキスト翻訳](#テキスト翻訳)** — 入力・言語の入れ替え・読み上げに対応した、通常の翻訳ウィンドウです

> 🌐 **OverTranslate は多言語インターフェースに対応しています。この README のスクリーンショットは繁体字中国語または英語の画面ですが、表示言語はアプリ内で切り替えられます。**

## キャプチャ翻訳

**メインウィンドウは閉じてタスクトレイに常駐できる**ので、ふだんは開いたままにしておく必要はありません。  
翻訳したいときにショートカットキー（既定 Ctrl + Alt + A）を押し、翻訳したい範囲を選ぶだけです。
> Web ページ、PDF、画像、漫画、動画、ゲームの画面など、文字を直接選択できない場面で使えます。

### ツールバー - そのほかの機能

範囲の選択が終わったあと、ツールバーから次の機能を使えます。

- **テキストをコピー**：認識したテキストをそのままクリップボードにコピーします。翻訳は不要です
- **スクリーンショット**：選んだ範囲をクリップボードにコピーします。設定の「スクリーンショットの保存」をオンにすると、画像ファイルとしても保存されます
- **マークアップ**：ペン、蛍光ペン、直線・四角・楕円などの図形でキャプチャに直接書き込み、その内容をスクリーンショットでコピー・保存できます。一部の設定は保存されます

## リアルタイム翻訳

**動画の字幕やゲーム画面、マンガ**など、翻訳し続けたい場面に向いています。範囲を選ぶと画面の内容を読み取り続け、  
文字が変わるたびに訳文を更新して元の位置に表示します。

取り込み方法は **画面全体** と **ウィンドウ指定** の 2 つです。  
画面全体は Windows 11 24H2 以降、ウィンドウ指定は Windows 10 1903 以降が必要です。

![リアルタイム翻訳のプレビュー](docs/images/即時翻譯視窗預覽_jp.png)

### 翻訳ブロックのモード（範囲選択）

> リアルタイム翻訳中はショートカットキー（既定 Ctrl + Alt + S）で一時停止・再開できます。  
> 翻訳が要らない場面や、原文をそのまま見たいときに一時停止し、あとで再開すれば、リアルタイム翻訳を終了する必要はありません。

翻訳ブロックには複数のモードと配置方法があります。
#### 字幕 / マンガ
動画の字幕、ゲームのストーリー会話、マンガの文字などに適しています。続けて読む文章が中心なら、このモードをお使いください。

### 原文対照

フローティングバーの「原文対照」をオンにすると、元の画面はそのままに、訳文を独立した対照枠に表示します。原文と訳文を見比べるのに便利です。
> 対照枠は自由にドラッグ・拡大縮小でき、ブロックごとに閉じることもできます。

## ポップアップ翻訳
> ショートカットキー（既定 `Ctrl + Alt + Q`）で、どの画面からでも開けます。

テキストを選んでショートカットキーを押すと、そのまま読み込んで翻訳します。何も選んでいないときは、直接入力もできます。  
ほかのウィンドウに切り替えると閉じます。出したままにしたいときはピン留めしてください。

![ポップアップ翻訳](docs/images/選詞翻譯.png)

---

## 置換翻訳
> ショートカットキー（既定 `Ctrl + Alt + E`）。翻訳してもウィンドウは開きません。

テキストを選んでショートカットキーを押すと、訳文がそのまま貼り付けられて原文と置き換わります（文字を入力できる欄でのみ動作し、入力欄以外には貼り付けられません）。

![置換翻訳](docs/images/快速翻譯.png)

## テキスト翻訳

**入力するだけで翻訳**でき、翻訳元と翻訳先の言語はすぐ入れ替えられます。  
音声合成（TTS）を内蔵しており、原文と訳文のどちらも読み上げられます。

![テキスト翻訳のプレビュー](docs/images/翻譯視窗預覽_jp.png)

## 設定

![設定ページ](docs/images/設定頁_jp.png)

| 設定項目 | 説明 |
|----------|------|
| 表示言語 | 繁體中文 / 简体中文 / English / 日本語 / 한국어。切り替えるとすぐ反映されます（初回起動時は Windows の表示言語に従います） |
| キャプチャ翻訳（ショートカットキー） | 範囲を選んでそのまま翻訳します（既定 `Ctrl + Alt + A`） |
| 翻訳ウィンドウを開く（ショートカットキー） | メインウィンドウを前回のページで呼び出します（既定 `Ctrl + Alt + W`）。リアルタイム翻訳中は、フローティングバーを最前面に移動します |
| 一時停止 / 再開（ショートカットキー） | **リアルタイム翻訳** を一時停止・再開します（既定 `Ctrl + Alt + S`）。停止中は原文を確認できます |
| ポップアップ翻訳（ショートカットキー） | **ポップアップ翻訳** のウィンドウを開きます（既定 `Ctrl + Alt + Q`）。選択中のテキストは自動で読み込まれます |
| 置換翻訳（ショートカットキー） | 選択中のテキストを訳文に置き換えます（既定 `Ctrl + Alt + E`）。翻訳元と翻訳先の言語は個別に設定できます |
| 自動翻訳 | キャプチャの範囲を選び終えた時点ですぐ翻訳し、クリックの手間をなくします（既定はオフ） |
| スタートアップ | Windows の起動時に自動で開始します |
| スクリーンショットの保存 | キャプチャのたびに自動で保存します。保存先は選べます（既定はオフ） |
| 翻訳サービスの設定 | 翻訳サービスのメニューに表示するサービスを選び、DeepL と OpenAI のキー・アドレス・モデルを設定します |
| テーマ | ライト / ダーク |
| アプリのログ | アプリの動作をより詳しく記録します。問題を調べるときだけの利用をおすすめします（既定はオフ） |
| デバッグツール | **キャプチャ翻訳** の結果に OCR 認識枠と文字グループ枠を重ねて表示します（既定はオフ） |

> ショートカットキーは組み合わせだけでなく、単独のキー（F1 ~ F24、Pause、Scroll Lock）、マウスの中ボタン／サイドボタン、ゲームパッドのボタンにもできます。

> ログはお使いの PC にのみ保存され、自動で送信されることはありません。**詳細な情報を記録する** をオンにしたときの内容も、同じく PC の中に残るだけです。問題を報告するときは、設定ページの **診断情報を書き出す** と **アップロード** を押してください。

### 翻訳 API

**一般のサービス**：インストールしてすぐ使えます。登録や API キーは不要です。

- Google 翻訳 (標準)
- Google 翻訳 (Beta)
- Bing 翻訳
- Microsoft 翻訳 **（既定）**
- Youdao 翻訳
- Tencent 翻訳

**カスタマイズできるサービス**：キーまたはサービスのアドレスを用意する必要があります（下の「動作環境」を参照）。

- DeepL
- OpenAI
  
**自動バックアップ**の仕組みがあります（**キャプチャ翻訳**・**リアルタイム翻訳**・**ポップアップ翻訳**・**置換翻訳** で働きます）。  
翻訳に失敗したり応答が遅かったりすると、まず同じサービスで再試行し、それでも翻訳できない場合にだけ使える別の翻訳サービスへ切り替わります。実際に使われたエンジンはツールバーに表示されます。
![バックアップ](docs/images/備援.png)

> **DeepL** と **OpenAI** の利用中はバックアップに切り替わりません。

### OpenAI の設定

![OpenAI](docs/images/OpenAI.png)

| 項目 | 説明 |
|------|------|
| API アドレス | 空欄なら `http://localhost:11434/v1`（Ollama のローカル既定アドレス）を使います |
| API キー | ローカル実行なら空欄で構いません |
| モデル設定 | 1 つの設定 = モデル名 + 詳細パラメーター + **自動** と **言語を指定** それぞれの System / User プロンプト。設定を切り替えるとまとめて切り替わります |
| 推奨設定 | 読み取り専用のもの。[Ollama の導入ガイド](docs/guides/OLLAMA_GUIDE.ja.md) が推奨するモデルを使い、プロンプトは表示言語に合わせて切り替わります |
| 追加 | 最大 5 つ。モデル名は必須で、System / User プロンプトはどちらか一方が入っていれば構いません |
| 詳細パラメーター | 編集画面の **詳細** にあります。3 つとも個別にオフにでき、オフのものは送信されません |

詳細パラメーター：

| パラメーター | 説明 | 範囲 | 既定 |
|--------------|------|------|------|
| Temperature | 確率の高い結果をどれだけ優先するか。値が大きいほど他の表現も選ばれやすくなります | 0.0 ~ 2.0 | 0.7 |
| Top P | モデルが選べる候補の範囲。値が小さいほど確率の高い少数の候補だけが残ります | 0.0 ~ 1.0 | 0.6 |
| Seed | 生成結果を再現しやすくします。モデル・プロンプト・その他の設定が同じなら、同じ Seed で同じ結果になりやすくなります | 整数 | 42 |

プロンプトで使えるパラメーター（設定ページの **使用できるパラメーター** にも説明と例があります）：

| パラメーター | 説明 | 例 |
|------|------|------|
| `{source_name}` | 翻訳元の言語名 | 英語 |
| `{source_code}` | 翻訳元の言語コード | en |
| `{target_name}` | 翻訳先の言語名 | 日本語 |
| `{target_code}` | 翻訳先の言語コード | ja |

> 言語名は表示言語に従います（日本語の画面なら「日本語」、English の画面なら「Japanese」）。言語コードはモデルが使うタグで固定です。

### 多言語 OCR

OCR は RapidOcrNet と ONNX モデルで処理し、言語に応じてモデルが自動で切り替わります。OCR エンジンを手で選ぶ必要はありません。

| 認識する言語 | 認識モデル（rec） |
|----------|----------------|
| **英語 / 中国語（簡体字・繁体字）/ 日本語** | PP-OCRv6 汎用認識モデル（`PP-OCRv6_small_rec`）。1 つのモデルで中国語・英語・日本語と各種ラテン文字に対応し、よくある中英混在も読めます |
| **韓国語** | PP-OCRv5 韓国語認識モデル（`korean_PP-OCRv5_rec`）。PP-OCRv6 の汎用モデルが覆っていない韓国語の文字を補います |

**文字検出モデル**（`PP-OCRv6_det_tiny`）と**方向分類モデル**（`cls`）はすべての言語で共通で、切り替わるのは認識モデルだけです。  
OCR は最初から最後までお使いの PC 上で動き、画像が外部のサービスに送られることはありません。標準のモデルは CPU で、漫画縦書きモデルはグラフィックスカードで動きます。

## 動作環境

- **OS**：Windows 10 / 11
- **ランタイム**：必要なものはインストーラーに含まれているため、.NET ランタイムを別途入れる必要はありません

次の翻訳サービスを使う場合は、別途用意が必要です。

- **DeepL**：[DeepL 公式サイト](https://www.deepl.com/pro-api) で API キーを取得してください
- **OpenAI**：OpenAI API 互換のサービスをご自身で用意してください。ローカル LLM の構築方法は [Ollama の導入ガイド](docs/guides/OLLAMA_GUIDE.ja.md) を参照してください
