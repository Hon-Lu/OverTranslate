# 截圖翻譯氣泡底板驗證

把 `CaptureBubbleBackdrop` 產出的底板直接合成回真實截圖，用來判斷「氣泡看不看得出是一張貼上去的卡」。對每張圖輸出三個變體：

- `00-original` —— 原圖
- `10-solid` —— 舊行為，整塊填 `SourceTextColorSampler` 取到的純色
- `40-shipping` —— 正式路徑：抹字修補 → 模糊 → 底色 wash → 文字／底板對比調整 → 邊緣羽化

`40-shipping` 完全走產品程式碼，這裡只負責把回傳的 BGRA 以 source-over 疊回去，也就是 WPF 拿到同一支筆刷會做的事。譯文是固定的中文佔位字串，用 GDI+ 以 `SourceFontScale` 算出的字級畫上去，只為了判斷可讀性，不代表實際排版。

## 執行

在儲存庫根目錄：

```powershell
dotnet run --project tools/CaptureBubbleProbe/CaptureBubbleProbe.csproj -c Release
dotnet run --project tools/CaptureBubbleProbe/CaptureBubbleProbe.csproj -c Release -- <圖片路徑> ...
```

不給參數時跑內建的六張：兩張遊戲面板、兩張漫畫、一張日文網頁、一張深色說明頁。需要本機 `.ai/test-images/`（不進版控）。

旗標：

- `--overflow[=n]` —— 把譯文寬度灌成原文的 n 倍（預設 1.45），模擬「譯文比原文長、氣泡長到原文所在的那塊東西之外」。輸出資料夾會加上 `-overflow<n>` 後綴。
- `--vertical` —— 以直書日文讀這張圖，對應工具列的直書切換。輸出資料夾加上 `-vertical` 後綴。

輸出在 `artifacts/capture-bubble/<集合>-<檔名>/`。OCR 結果快取在同資料夾的 `ocr.json`，刪掉才會重跑辨識。

## 平滑度分流

底板不是無條件套用。`CaptureBubbleBackdrop` 對每個氣泡量兩件事，決定它要底板還是舊的純色卡：

- **平滑度**：氣泡**及其周圍兩倍字高**的鄰域裡，左右相鄰像素每個色版差 <= 2 的比例。在修補後的畫面上量（原文已被抹掉，否則抗鋸齒文字會把介面與照片拉到同一個數字）。
- **色彩集中度**：氣泡底下最大兩個 4-bit 色桶的佔比。

| 鄰域 | 平滑度 | 用純色卡的條件 |
|---|---|---|
| 介面 | >= 0.82 | 集中度 >= 0.45 |
| 圖像 | < 0.82 | 集中度 >= 0.85 |

78 個標註氣泡實測：應用程式 UI、網頁、漫畫平塗 0.82-1.00，遊戲畫面 0.45-0.98。

### 為什麼是鄰域、為什麼容許 +-2

這兩個修飾都是被實際案例逼出來的，不要退回去：

- **整張圖一個數字不行**：雜誌式網頁大半是銳利排版、中間嵌照片，整張平均會把它判成照片，然後去糊它的按鈕。BanG Dream 那張的粉紅色 `リリース` 標籤變成一團粉紅光暈就是這樣來的。
- **只量氣泡底下不行**：一顆按鈕單獨看跟照片一樣平滑。要不要糊，是由它**周圍**決定的。
- **要求完全相等不行**：淺色漸層頁面（帶浮水印）相鄰像素差 1-2，會被判成照片。容許 +-2 之後同一張頁面從 0.485 變成 0.903。

門檻不對稱是刻意的：銳利介面上一塊糊掉的區域會把旁邊的按鈕邊框與膠囊外框抹掉，看起來像壞了，所以底板要自己掙來；圖像上純色卡才是突兀的那個，所以底板是預設。

## 已經量過的

- 六張樣本上，`40-shipping` 的模糊半徑＝字高 ×0.30、羽化寬＝字高 ×0.35、wash 0.25。0.15 與 0.30 的模糊肉眼難分，0.50 開始發軟。
- **羽化是決定性的**：同樣參數但硬邊，遊戲畫面上仍看得到矩形輪廓。
- 平底（深色網頁、漫畫黑框）三個變體看不出差別，不需要另做複雜度分流。
- wash 往取樣背景色疊不會增加對比，那是文字顏色與 lift 的工作。
- 整張畫面修補 29–144ms（870×1236 至 2365×1265，3–70 個區塊），在背景執行緒跑一次。
- 擴充驗證（2026-09-16）：英文網頁三張幾乎不動（最大差 22），韓文遊戲面板與影片字幕各有一張走底板且明顯較好，直排日文十張裡四張維持純色卡、兩張走底板、兩張讀不到文字。
- **影片字幕是底板的收益情境**：純色卡在動畫場景上是一條橫跨畫面的灰褐色長條，底板讓字幕像原生燒錄上去的。
- **已知瑕疵**：漫畫對白框（直排那組）走底板時，修補＋模糊會在白色對白框內留下一小塊柔和污漬，純色卡沒有。輕微但看得到，尚未處理。
