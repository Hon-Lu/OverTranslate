# ローカル LLM 導入ガイド（Ollama を例に）

> **Language:** **[繁體中文](OLLAMA_GUIDE.md)** ｜ **[English](OLLAMA_GUIDE.en.md)** ｜ **[简体中文](OLLAMA_GUIDE.zh-Hans.md)** ｜ **日本語 ✓** ｜ **[한국어](OLLAMA_GUIDE.ko.md)**

OverTranslate の **OpenAI** 翻訳サービスは OpenAI API 互換形式に対応しているため、[Ollama](https://ollama.com/) を使って、自分の PC 上でローカルモデルを動かすこともできます。

ローカルモデルなら別途 API 料金はかからず、翻訳する内容を外部サーバーへ送信する必要もありません。

> このガイドでは Ollama を例に説明します。LM Studio や OpenRouter など、ほかの OpenAI 互換サービスも使えます。設定方法は末尾の「4. ほかの OpenAI 互換サービスを使う」を参照してください。

このガイドでは `hf.co/unsloth/Hy-MT2-7B-GGUF:UD-IQ3_XXS` を例に説明します。Hy-MT2 は Tencent が公開している翻訳向けモデルで、33 言語の相互翻訳に対応しています。ここでは Unsloth が再パッケージした、容量の小さいバージョンを使用します。

> **どれくらいの PC スペックが必要？**
>
> ローカルモデルは PC の CPU と GPU を使用します。快適な翻訳速度を得るには、独立 GPU を搭載した PC をおすすめします。
>
> このガイドで使うモデルはダウンロード時で約 **3.1 GB**、読み込み後はおよそ **4.1 GB の VRAM** を使用するため、グラフィックスカードは **6 GB 以上の VRAM** を目安にしてください。
>
> ゲームをしながら OverTranslate を使う場合は、ゲーム側も VRAM を使用します。その場合は **8 GB 以上**あると余裕があります。
>
> 実際の使用量は Ollama、翻訳する文章の長さ、ほかのアプリの GPU 使用状況などによって変わります。
>
> VRAM が足りないと、モデルの一部が CPU 側で処理され、翻訳速度が大きく落ちることがあります。その場合は、下で紹介する小さいバージョンを試してください。

## 1. Ollama をインストールする

1. [Ollama 公式サイト](https://ollama.com/download) を開き、お使いの OS に合ったバージョンをダウンロードします
2. インストーラーを実行し、基本的には既定の設定のままインストールを完了します

インストールが終わったら Ollama を起動します。

Ollama の既定の API アドレスは次のとおりです。

`http://localhost:11434`

Ollama の設定を変更していなければ、このままで問題ありません。

## 2. 翻訳モデルをダウンロードする

Windows の「コマンド プロンプト」または「PowerShell」を開き、次を実行します。

```text
ollama pull hf.co/unsloth/Hy-MT2-7B-GGUF:UD-IQ3_XXS
```

あとはダウンロードが完了するまで待ちます。

このバージョンは約 **3.1 GB** です。ダウンロード時間は回線速度によって変わります。

> **別のサイズを使いたい場合**
>
> [unsloth/Hy-MT2-7B-GGUF](https://huggingface.co/unsloth/Hy-MT2-7B-GGUF) から、同じモデルの別の量子化バージョンを選べます。
>
> 使いたいものが決まったら、モデル名を次の形式に変更してください。
>
> `hf.co/unsloth/Hy-MT2-7B-GGUF:<バージョン名>`
>
> 一般に、ファイルが小さいほど必要なハードウェア性能も下がり、軽く動かせます。その代わり、翻訳品質が少し下がる場合があります。

ほかのモデルを探したい場合は、次のサイトも利用できます。

- [Ollama Models](https://ollama.com/search)：Ollama 向けに用意されたモデルをそのまま探せるため、いちばん簡単です。
- [Hugging Face](https://huggingface.co/models)：より多くのモデルから選べます。Ollama で使う場合は、**GGUF 版がすでに用意されているモデル**を選ぶのがおすすめです。リポジトリ名に `GGUF` が含まれていたり、`-GGUF` で終わっていたりすることがよくあります。

Hugging Face に Safetensors などの元モデルしかなく、GGUF 版が用意されていない場合は、対応しているモデルを [llama.cpp](https://github.com/ggml-org/llama.cpp) で GGUF に変換してから Ollama に取り込む必要があります。

どれを選べばよいかわからない場合は、このガイドの推奨モデルをそのまま使うのが簡単です。また、OverTranslate のようなリアルタイム翻訳用途では、**思考モードを使わないモデル**をおすすめします。既定で思考してから答えるモデルを使う場合は、モデル設定の **詳細** で **思考をオフにする** にチェックを入れてください。

## 3. OverTranslate を設定する

モデルのダウンロードが終わったら、OverTranslate に戻ります。

1. **設定**を開きます
2. 翻訳サービスで **OpenAI** を選びます
3. **API アドレス**と **API Key** はどちらも空欄のままで構いません
4. **モデル設定**は既定の推奨設定のままにします
5. 設定画面を閉じれば、ローカルモデルで翻訳を始められます

API アドレスを空欄にすると、OverTranslate は Ollama の既定のローカルアドレスを使用します。ローカルで動かしている Ollama には API Key も必要ありません。

OverTranslate の既定の推奨設定では、このガイドで紹介しているモデルがすでに設定されています。

`hf.co/unsloth/Hy-MT2-7B-GGUF:UD-IQ3_XXS`

対応するプロンプトや詳細パラメーターも設定済みなので、そのまま使いたい場合は**追加で設定を変更する必要はありません**。

> **別のモデルを使いたい場合**
>
> **設定一覧**から **追加**を選び、完全なモデル名を入力して保存し、作成した設定を選択してください。プロンプトはまず既定のままで使い、必要に応じてそのモデルの説明に従って調整できます。
>
> Hugging Face のモデルを使う場合は、先頭の `hf.co/` を含めた完全な名前を入力してください。
>
> 1 つのモデル設定には次の内容がまとめて保存されます。
>
> - モデル名
> - 詳細パラメーター（Temperature、Top P、Seed、思考をオフにする）
> - 翻訳モード（標準 / 一括）
> - プロンプト
>
> モデル設定を切り替えると、これらもまとめて切り替わります。

> **プロンプトと詳細パラメーターについて**
>
> OverTranslate の内蔵プロンプトは現在のインターフェース言語に合わせて切り替わり、推奨の Hy-MT2 モデル向けに調整済みです。
>
> 1 つのモデル設定にプロンプトは 1 つだけで、System Prompt は使いません。これは推奨モデルの公式ドキュメントで案内されている形式に合わせたものです。
>
> モデルによって必要なプロンプト形式は異なります。別のモデルを追加するときは、そのモデルの説明に従って調整してください。
>
> 推奨モデルでは、詳細パラメーターを次の値に設定しています。
>
> - Temperature：`0.7`
> - Top P：`0.6`
> - Seed：`42`
>
> これらは推奨モデルのドキュメントで案内されている設定値です。Seed を固定しておくことで、同じ原文・同じ設定では、より一貫した翻訳結果を得やすくなります。

## 4. ほかの OpenAI 互換サービスを使う

LM Studio や OpenRouter など、OpenAI 互換 API を提供するサービスも使えます。そのサービスの API アドレスと API Key を設定に入力し、そのモデル名でモデル設定を追加してください。詳しくは各サービスのドキュメントを参照してください。
