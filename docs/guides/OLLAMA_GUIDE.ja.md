# Ollama でローカル翻訳モデルを使う

> **Language:** **[繁體中文](OLLAMA_GUIDE.md)** ｜ **[English](OLLAMA_GUIDE.en.md)** ｜ **[简体中文](OLLAMA_GUIDE.zh-Hans.md)** ｜ **日本語 ✓** ｜ **[한국어](OLLAMA_GUIDE.ko.md)**

OverTranslate の **OpenAI** 翻訳サービスは OpenAI API 互換形式に対応しているため、[Ollama](https://ollama.com/) と組み合わせて自分のパソコンで翻訳モデルを動かせます。翻訳内容はパソコンの外に出ず、外部の翻訳 API の料金もかかりません。

このガイドでは、Ollama と Hy-MT2 翻訳モデルを例に説明します。以下の手順でインストールと設定を行えば、すぐに使い始められます。LM Studio や OpenRouter など、ほかの OpenAI 互換サービスも使えます（末尾の「ほかの OpenAI 互換サービスを使う」を参照）。

## 必要なスペック

このガイドで使うモデルは約 **3.1 GB** で、読み込むと約 **4.1 GB の VRAM** を使います。**6 GB 以上の VRAM** を備えたグラフィックスカードをおすすめします。ゲームなど GPU を使うほかのプログラムと同時に動かす場合は、**8 GB 以上の VRAM** をおすすめします。

実際の使用量は、翻訳する内容やほかのプログラムによって変わります。VRAM が足りないと処理の一部が CPU に回り、翻訳が遅くなります。その場合は、より小さいバージョンを使ってください（「ほかのモデルを使う」を参照）。

## 1. Ollama をインストールする

[Ollama 公式サイト](https://ollama.com/download) からダウンロードし、既定の設定のままインストールします。インストールが終わったら Ollama を起動し、OverTranslate で翻訳する間は起動したままにしておいてください。

## 2. 翻訳モデルをダウンロードする

Windows の「コマンド プロンプト」または「PowerShell」を開き、次のコマンドを実行します。

```text
ollama pull hf.co/unsloth/Hy-MT2-7B-GGUF:UD-IQ3_XXS
```

ダウンロードが終わるまで待ちます。モデルファイルは約 **3.1 GB** で、かかる時間は回線速度によって変わります。

Hy-MT2 は Tencent が公開している翻訳専用モデルで、33 言語の相互翻訳に対応しています。ここでは Unsloth が再パッケージした、サイズの小さいバージョンを使います。

## 3. OverTranslate を設定する

1. OverTranslate の **設定** を開きます。
2. 翻訳サービスで **OpenAI** を選びます。
3. **API アドレス** と **API キー** は空欄のままにします。
4. **モデル設定** は既定の **システム既定** のままにします。

これで翻訳を始められます。API アドレスが空欄のとき、OverTranslate は Ollama のローカルアドレス `http://localhost:11434/v1` を使います。ローカルの Ollama には API キーは不要です。**システム既定** にはこのガイドで使うモデル、プロンプト、詳細パラメーターがすでに入っているため、変更する必要はありません。

## ほかのモデルを使う

### 同じモデルの別サイズ

[unsloth/Hy-MT2-7B-GGUF](https://huggingface.co/unsloth/Hy-MT2-7B-GGUF) でほかの量子化バージョンを選び、コマンド末尾のバージョン名を置き換えます。

```text
ollama pull hf.co/unsloth/Hy-MT2-7B-GGUF:<バージョン名>
```

ファイルが小さいほど必要なハードウェア性能は下がりますが、翻訳品質も下がることがあります。

### 別のモデル

[Ollama Models](https://ollama.com/search) や [Hugging Face](https://huggingface.co/models) で探せます。

Hugging Face のモデルを使う場合は、**GGUF** 版が用意されているものを選んでください。Safetensors などの元の形式しかない場合は、変換できるモデルかどうかを確認したうえで、[llama.cpp](https://github.com/ggml-org/llama.cpp) で GGUF に変換してから Ollama に取り込む必要があります。

### モデル設定を切り替える

1. OverTranslate の **モデル設定** で **設定を追加** を選びます。
2. モデル名を入力して保存し、作成した設定を選びます。
3. 必要に応じて、モデルのドキュメントに従ってプロンプトと詳細パラメーターを調整します。

Hugging Face からダウンロードしたモデルは、名前の先頭に `hf.co/` が必要です。例：

```text
hf.co/unsloth/Hy-MT2-7B-GGUF:UD-IQ3_XXS
```

モデル設定ごとに、モデル名、詳細パラメーター、翻訳モード、プロンプトがまとめて保存され、設定を切り替えるとこれらも一緒に切り替わります。

モデルによって適したプロンプトやパラメーターは異なるため、まずはモデル自体の説明を確認してください。OverTranslate の内蔵プロンプトは表示言語に合わせて切り替わり、推奨の Hy-MT2 モデル向けに調整されています。

**システム既定** の詳細パラメーターは次のとおりです。

- Temperature：`0.7`
- Top P：`0.6`
- Seed：`42`

これらの値は推奨モデルの公式ドキュメントに従っています。Seed を固定すると、同じ設定で安定した結果を得やすくなります。モデルが考えてから訳文を出力する場合は、モデル設定の **詳細** で **思考をオフにする** にチェックを入れてください。リアルタイム翻訳には、訳文をすぐに出力するモデルのほうが向いています。

## ほかの OpenAI 互換サービスを使う

LM Studio や OpenRouter などのサービスも OverTranslate で使えます。翻訳サービスの設定にそのサービスの **API アドレス** と **API キー** を入力し、モデル設定を追加してモデル名を入力してください。そのほかの設定方法は各サービスのドキュメントを参照してください。
