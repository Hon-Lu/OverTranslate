# 로컬 LLM 설치 가이드 (Ollama 예시)

> **Language:** **[繁體中文](OLLAMA_GUIDE.md)** ｜ **[English](OLLAMA_GUIDE.en.md)** ｜ **[简体中文](OLLAMA_GUIDE.zh-Hans.md)** ｜ **[日本語](OLLAMA_GUIDE.ja.md)** ｜ **한국어 ✓**

OverTranslate의 **OpenAI** 번역 서비스는 OpenAI API 호환 형식을 지원하므로, [Ollama](https://ollama.com/)를 이용해 내 컴퓨터에서 로컬 모델을 직접 실행할 수 있습니다.

로컬 모델을 사용하면 별도의 API 비용이 들지 않고, 번역할 내용을 외부 서버로 보낼 필요도 없습니다.

> 이 가이드는 Ollama를 예로 들어 설명합니다. LM Studio, OpenRouter 같은 다른 OpenAI 호환 서비스도 사용할 수 있으며, 설정 방법은 마지막의 「4. 다른 OpenAI 호환 서비스 사용하기」를 참고하세요.

이 가이드에서는 `hf.co/unsloth/Hy-MT2-7B-GGUF:UD-IQ3_XXS`를 예로 사용합니다. Hy-MT2는 Tencent가 공개한 번역 특화 모델로 33개 언어 간 번역을 지원하며, 여기서는 Unsloth가 다시 패키징한 더 작은 버전을 사용합니다.

> **어느 정도의 PC 사양이 필요한가요?**
>
> 로컬 모델은 컴퓨터의 CPU와 GPU를 사용합니다. 번역 속도를 더 쾌적하게 유지하려면 외장 그래픽 카드가 있는 PC를 권장합니다.
>
> 이 가이드에서 사용하는 모델은 다운로드 크기가 약 **3.1 GB**이고, 불러온 뒤에는 약 **4.1 GB의 VRAM**을 사용합니다. 따라서 그래픽 카드는 **최소 6 GB VRAM**을 권장합니다.
>
> 게임을 하면서 OverTranslate를 함께 사용할 예정이라면 게임도 VRAM을 사용하므로 **8 GB 이상**이면 더 여유롭습니다.
>
> 실제 사용량은 Ollama, 번역할 문장의 길이, 다른 프로그램의 GPU 사용량 등에 따라 달라질 수 있습니다.
>
> VRAM이 부족하면 모델의 일부가 CPU에서 실행되어 번역 속도가 크게 느려질 수 있습니다. 이런 경우에는 아래에서 소개하는 더 작은 버전을 사용해 보세요.

## 1. Ollama 설치

1. [Ollama 공식 사이트](https://ollama.com/download)에서 사용 중인 운영체제에 맞는 버전을 다운로드합니다
2. 설치 프로그램을 실행한 뒤 기본 옵션으로 설치를 완료합니다

설치가 끝나면 Ollama를 실행합니다.

Ollama의 기본 API 주소는 다음과 같습니다.

`http://localhost:11434`

Ollama 설정을 따로 변경하지 않았다면 기본값을 그대로 사용하면 됩니다.

## 2. 번역 모델 다운로드

Windows의 '명령 프롬프트' 또는 'PowerShell'을 열고 다음 명령을 입력합니다.

```text
ollama pull hf.co/unsloth/Hy-MT2-7B-GGUF:UD-IQ3_XXS
```

이제 다운로드가 끝날 때까지 기다리면 됩니다.

이 버전의 크기는 약 **3.1 GB**이며, 다운로드 시간은 인터넷 속도에 따라 달라집니다.

> **다른 크기의 버전을 사용하고 싶다면**
>
> [unsloth/Hy-MT2-7B-GGUF](https://huggingface.co/unsloth/Hy-MT2-7B-GGUF)에서 같은 모델의 다른 양자화 버전을 선택할 수 있습니다.
>
> 사용할 버전을 골랐다면 모델 이름을 다음 형식으로 바꾸세요.
>
> `hf.co/unsloth/Hy-MT2-7B-GGUF:<버전 이름>`
>
> 일반적으로 파일이 작을수록 필요한 하드웨어 자원이 줄어들고 더 가볍게 실행할 수 있지만, 번역 품질도 다소 낮아질 수 있습니다.
>
> 그래픽 카드가 **4 GB VRAM**만 지원한다면 더 작은 `maternion/hy-mt2:1.8b`를 권장합니다. 모델 파일은 약 **1.1 GB**입니다.

다른 모델을 찾고 싶다면 다음 사이트도 이용할 수 있습니다.

- [Ollama Models](https://ollama.com/search): Ollama에서 바로 사용할 수 있도록 준비된 모델을 찾을 수 있어 가장 간단합니다.
- [Hugging Face](https://huggingface.co/models): 훨씬 더 많은 모델을 찾을 수 있습니다. Ollama에서 사용할 목적이라면 **GGUF 버전이 이미 제공되는 모델**을 우선 선택하세요. 이런 저장소는 이름에 `GGUF`가 들어가거나 `-GGUF`로 끝나는 경우가 많습니다.

Hugging Face에 Safetensors 같은 원본 모델만 있고 GGUF 버전이 없다면, 호환되는 모델을 [llama.cpp](https://github.com/ggml-org/llama.cpp)로 GGUF 형식으로 변환한 뒤 Ollama에 가져와야 합니다.

어떤 모델을 골라야 할지 잘 모르겠다면 이 가이드의 권장 모델을 그대로 사용하는 것이 가장 간단합니다. 또한 OverTranslate처럼 실시간 번역에 사용할 때는 **사고/추론 모드를 사용하지 않는 모델**을 권장합니다.

## 3. OverTranslate 설정

모델 다운로드가 끝나면 OverTranslate로 돌아갑니다.

1. **설정**을 엽니다
2. 번역 서비스에서 **OpenAI**를 선택합니다
3. **API 주소**와 **API Key**는 모두 비워 둡니다
4. **모델 설정**은 기본 권장 설정을 그대로 사용합니다
5. 설정 화면을 닫으면 로컬 모델로 번역을 시작할 수 있습니다

API 주소를 비워 두면 OverTranslate가 Ollama의 기본 로컬 주소를 사용합니다. 로컬에서 실행 중인 Ollama에는 API Key도 필요하지 않습니다.

OverTranslate의 기본 권장 설정에는 이 가이드에서 사용하는 모델이 이미 지정되어 있습니다.

`hf.co/unsloth/Hy-MT2-7B-GGUF:UD-IQ3_XXS`

해당 모델에 맞는 프롬프트와 고급 파라미터도 미리 설정되어 있으므로, 그대로 사용할 목적이라면 **추가로 수정할 설정은 없습니다**.

> **다른 모델을 사용하고 싶다면**
>
> **설정 목록**에서 **추가**를 누르고 전체 모델 이름과 해당 모델에 필요한 프롬프트를 입력한 뒤 저장합니다. 이후 새로 만든 설정을 선택하면 됩니다.
>
> Hugging Face 모델을 사용하는 경우에는 앞의 `hf.co/`까지 포함한 전체 이름을 입력하세요.
>
> 하나의 모델 설정에는 다음 항목이 함께 저장됩니다.
>
> - 모델 이름
> - Temperature
> - 언어 자동 감지 시 사용하는 System / User 프롬프트
> - 원문 언어를 지정했을 때 사용하는 System / User 프롬프트
>
> 모델 설정을 바꾸면 이 항목들도 함께 전환됩니다.

> **프롬프트와 고급 파라미터에 대해**
>
> OverTranslate의 기본 프롬프트는 현재 인터페이스 언어에 맞춰 바뀌며, 권장 Hy-MT2 모델에 맞게 조정되어 있습니다.
>
> 이 모델은 기본적으로 **User Prompt**만 사용하고 **System Prompt**는 사용하지 않습니다. 이는 모델 공식 문서에서 안내하는 사용 방식에 맞춘 설정입니다.
>
> 모델마다 필요한 프롬프트 형식은 다를 수 있습니다. 다른 모델을 추가할 때는 해당 모델의 설명을 참고해 설정하세요. System Prompt와 User Prompt를 모두 입력할 필요는 없으며, 둘 중 하나만 입력되어 있어도 사용할 수 있습니다.
>
> 권장 모델의 고급 파라미터 기본값은 다음과 같습니다.
>
> - Temperature: `0.7`
> - Top P: `0.6`
> - Seed: `42`
>
> 이 값들은 권장 모델 문서에서 안내하는 설정을 기준으로 합니다. Seed를 고정하면 같은 원문과 같은 설정에서 보다 일관된 번역 결과를 얻기 쉬워집니다.

## 4. 다른 OpenAI 호환 서비스 사용하기

LM Studio, OpenRouter 등 OpenAI 호환 API를 제공하는 서비스도 사용할 수 있습니다. 해당 서비스의 API 주소와 API Key를 설정에 입력하고, 그 모델 이름으로 모델 설정을 추가하면 됩니다. 자세한 내용은 해당 서비스의 문서를 참고하세요.
