翻译功能

五种翻译方式，按情境选择

OverTranslate 提供五种翻译功能，都能用快捷键直接叫出。

  • Ctrl + Alt + A

    截图翻译

    框选画面内容，识别并将译文直接显示在原画面。
  • 从主窗口启动

    实时翻译

    框选视频、游戏或漫画的内容，持续识别并将译文显示在原画面。
  • Ctrl + Alt + Q

    取词翻译

    选取文字后打开精简翻译小窗口，也可固定常驻使用。
  • Ctrl + Alt + E

    快速翻译

    选取文字后按下快捷键，直接翻译并替换原文。
  • Ctrl + Alt + W

    文字翻译

    使用完整翻译窗口，支持文字输入、语言互换与文字朗读。

网站中的应用程序画面统一以繁体中文显示，实际界面可切换为繁體中文、简体中文、English、日本語、한국어。

截图翻译

框选画面，译文直接覆盖原文

按下快捷键框选需要翻译的区域，即可识别并翻译画面文字。支持网页、PDF、图片、漫画、影音与游戏，并可自动识别繁体中文、简体中文、英文、日文与韩文。

主窗口可以直接关闭，程序常驻系统托盘，平时不需要一直开着。

工具栏还能做这些

  • 复制文字不需翻译即可将识别出的文字复制到剪贴板。
  • 截图将框选画面复制到剪贴板，也可在设置中开启「保存截图」同步存档。
  • 标记用画笔工具直接在截图上标记，再复制或保存画面内容。

实时翻译

画面文字变动，译文实时更新

框选翻译区域后，持续识别画面文字并自动更新译文。适用于视频字幕、游戏画面与漫画阅读，译文直接显示于原位置。

两种画面来源

可抓取整个屏幕，或指定单一窗口。

随时暂停与继续

暂停时可直接查看原文，不必关闭。

适合影音字幕、游戏剧情对话、漫画文字等情境；若内容以连续阅读的文字为主，建议使用此模式。

适合游戏画面、聊天室、菜单与界面文字等情境；若内容不是字幕、剧情对话或漫画文字，建议使用此模式。

显示样式可按需求调整

文字颜色与底色支持自动或固定设置，并可调整底色透明度、边框与预览效果。

其他翻译功能

选取、输入，都能直接翻译

Ctrl + Alt + Q

选取文字后按下快捷键，即可自动带入并翻译；未选取文字时也可直接输入，窗口亦可固定持续显示。

Ctrl + Alt + E

选取文字后按下快捷键，翻译结果会自动粘贴并替换原文，无需打开其他窗口；适用于可输入文字的栏位。

Ctrl + Alt + W

输入或粘贴文字即可翻译，可快速互换源语言与目标语言，并支持原文与译文朗读。

自动备援

当某个翻译服务无法使用或响应过慢时，会自动切换到其他可用的服务，不需要自己重试或改设置。

外部翻译服务与 AI 模型

除了内置服务，也能自行加入其他翻译服务，或使用本地 AI 模型进行翻译；不额外设置也不影响一般使用。

隐私

画面与数据皆保留于本机

画面只在本机识别，图片不会上传。翻译时仅传送识别出的文字；若使用本地 AI 模型，整个流程都能在电脑上完成。

应用日志仅保存在本机，不会自动上传。

1 · 框选画面
框选的范围仅保留在本机。
2 · 识别文字
文字识别同样在本机完成，图片不会外传。
3 · 翻译
仅将识别出的文字送往所选的翻译服务。

设置

按使用习惯调整

  • 界面语言支持繁体中文、简体中文、英文、日文与韩文，切换后立即生效；首次启动时会按 Windows 显示语言自动套用。
  • 快捷键支持组合键、单键、鼠标按键与游戏手柄按键，可按使用习惯自定义。
  • 主题提供浅色与深色两种显示模式。
  • 自动翻译截图框选完成后可立即翻译，无需手动点击按钮。
  • 开机启动与截图保存可设置开机自动启动，并自动保存截图与指定保存位置。

系统需求

  • 操作系统Windows 10 / 11。实时翻译的屏幕抓取需 Windows 11 24H2 以上，窗口抓取需 Windows 10 1903 以上。
  • 运行环境安装包已内含所需环境，不需另外安装其他组件。
  • 高级选项使用 DeepL 或自行搭建的 AI 模型时需自备密钥或服务地址，内置的翻译服务则不需设置。
