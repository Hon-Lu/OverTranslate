OverTranslate 화면에 보이는 글자는 그대로 번역할 수 있습니다

만화·영상·게임에 쓸 수 있는 Windows 화면 번역 도구. 캡처 번역과 실시간 번역 등 여러 번역 기능을 지원합니다.

무료로 내려받기

번역 기능

다섯 가지 번역 방식, 상황에 맞게

OverTranslate에는 다섯 가지 번역 기능이 있고 모두 단축키로 바로 부를 수 있습니다.

  • Ctrl + Alt + A

    캡처 번역

    화면의 영역을 지정하면 글자를 인식해 번역문을 그 자리에 겹쳐 보여 줍니다.
  • 메인 창에서 시작

    실시간 번역

    영상, 게임, 만화의 영역을 지정하면 글자를 계속 인식해 번역문을 그 자리에 겹쳐 보여 줍니다.
  • Ctrl + Alt + Q

    빠른 조회

    텍스트를 선택하면 작은 번역 창이 열리며, 고정해 계속 띄워 둘 수도 있습니다.
  • Ctrl + Alt + E

    빠른 번역

    텍스트를 선택하고 단축키를 누르면 그 자리에서 번역문으로 바뀝니다.
  • Ctrl + Alt + W

    텍스트 번역

    입력, 언어 바꾸기, 읽어 주기를 지원하는 전체 번역 창입니다.

이 사이트의 앱 화면은 모두 번체 중국어로 표시했습니다. 실제 화면은 繁體中文, 简体中文, English, 日本語, 한국어로 바꿀 수 있습니다.

캡처 번역

영역을 지정하면 번역문이 원문 위를 덮습니다

단축키를 누르고 번역할 영역을 지정하면 화면의 글자를 인식해 번역합니다. 웹 페이지, PDF, 이미지, 만화, 영상, 게임에서 쓸 수 있고 번체 중국어, 간체 중국어, 영어, 일본어, 한국어를 자동으로 인식합니다.

메인 창은 닫아도 됩니다. 프로그램이 시스템 트레이에 상주하므로 평소에 계속 띄워 둘 필요가 없습니다.

툴바로 할 수 있는 일

  • 텍스트 복사번역하지 않고 인식한 글자를 그대로 클립보드로 복사합니다.
  • 스크린샷지정한 영역을 클립보드로 복사하고, 설정에서 「스크린샷 저장」을 켜면 파일로도 저장합니다.
  • 표시펜 도구로 캡처 위에 직접 표시한 뒤, 그대로 복사하거나 저장할 수 있습니다.

실시간 번역

화면 글자가 바뀌면 번역문도 바로 갱신

번역할 영역을 지정하면 화면의 글자를 계속 인식해 번역문을 자동으로 갱신합니다. 영상 자막, 게임 화면, 만화 읽기에 적합하며 번역문은 원래 위치에 그대로 표시됩니다.

두 가지 가져오기 방식

전체 화면을 가져오거나 특정 창만 지정할 수 있습니다.

언제든 일시 정지와 재개

일시 정지하면 종료하지 않고 원문을 볼 수 있습니다.

영상 자막, 게임 스토리 대사, 만화 글자 등에 적합합니다. 이어서 읽는 문장이 중심이라면 이 모드를 사용하세요.

게임 화면, 채팅창, 메뉴, 인터페이스 문구 등에 적합합니다. 자막이나 스토리 대사, 만화 글자가 아니라면 이 모드를 사용하세요.

표시 방식은 원하는 대로 조정

글자 색과 배경색은 자동과 고정 중에서 고를 수 있고, 배경 투명도와 테두리, 미리 보기도 조정할 수 있습니다.

그 외 번역 기능

선택하든 입력하든, 바로 번역

Ctrl + Alt + Q

텍스트를 선택하고 단축키를 누르면 자동으로 불러와 번역합니다. 아무것도 선택하지 않았다면 직접 입력할 수도 있고, 창을 고정해 계속 띄워 둘 수도 있습니다.

Ctrl + Alt + E

텍스트를 선택하고 단축키를 누르면 번역 결과가 그대로 붙여넣어져 원문을 대체합니다. 창은 열리지 않으며 글자를 입력할 수 있는 칸에서 동작합니다.

Ctrl + Alt + W

입력하거나 붙여 넣은 텍스트를 바로 번역하고, 원본 언어와 번역할 언어를 빠르게 바꿀 수 있으며, 원문과 번역문 모두 읽어 줍니다.

자동 대체

어떤 번역 서비스가 동작하지 않거나 응답이 너무 느리면 사용할 수 있는 다른 서비스로 자동으로 바뀝니다. 직접 다시 시도하거나 설정을 바꿀 필요가 없습니다.

외부 번역 서비스와 AI 모델

내장 서비스 외에 다른 번역 서비스를 직접 추가하거나 로컬 AI 모델로 번역할 수 있습니다. 둘 다 설정하지 않아도 일반적인 사용에는 지장이 없습니다.

로컬 AI 모델 설치 안내

개인정보

화면과 데이터 모두 내 PC에 남습니다

화면은 내 PC에서만 인식하며 이미지는 올라가지 않습니다. 번역할 때 보내는 것은 인식된 글자뿐이고, 로컬 AI 모델을 쓰면 그 과정까지 내 PC에서 끝납니다.

로그는 내 PC에만 저장되고 자동으로 전송되지 않습니다.

1 · 영역 지정
지정한 영역은 이 PC 안에만 있습니다.
2 · 글자 인식
인식도 이 PC에서 이루어지며 이미지는 밖으로 나가지 않습니다.
3 · 번역
선택한 번역 서비스로 보내는 것은 글자뿐입니다.

설정

쓰는 방식에 맞게 조정

  • 인터페이스 언어번체 중국어, 간체 중국어, 영어, 일본어, 한국어를 지원하며 바꾸면 바로 적용됩니다. 처음 실행할 때는 Windows 표시 언어를 자동으로 따릅니다.
  • 단축키조합키, 단일 키, 마우스 버튼, 게임패드 버튼을 지원하며 쓰는 방식에 맞게 지정할 수 있습니다.
  • 테마밝은 테마와 어두운 테마 두 가지를 제공합니다.
  • 자동 번역캡처 영역을 지정하는 즉시 번역하므로 버튼을 따로 누를 필요가 없습니다.
  • 시작 프로그램과 캡처 저장Windows 시작 시 자동으로 실행하고, 캡처를 지정한 위치에 자동으로 저장할 수 있습니다.

시스템 요구 사항

  • 운영체제Windows 10 / 11. 실시간 번역의 전체 화면 가져오기는 Windows 11 24H2 이상, 창 지정은 Windows 10 1903 이상이 필요합니다.
