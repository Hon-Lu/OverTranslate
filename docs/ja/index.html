OverTranslate 画面に見えている文字は、そのまま翻訳できます

漫画・動画・ゲームで使える Windows 用の画面翻訳ツール。キャプチャ翻訳やリアルタイム翻訳など、複数の翻訳機能に対応しています。

翻訳機能

5 つの翻訳方法から、場面に合うものを

OverTranslate には 5 つの翻訳機能があり、どれもショートカットキーから直接呼び出せます。

  • Ctrl + Alt + A

    キャプチャ翻訳

    画面の範囲を選ぶと、文字を読み取って訳文をその場に重ねて表示します。
  • メインウィンドウから

    リアルタイム翻訳

    動画・ゲーム・マンガの範囲を選ぶと、文字を読み取り続けて訳文をその場に重ねて表示します。
  • Ctrl + Alt + Q

    クイック辞書

    テキストを選ぶと小さな翻訳ウィンドウが開きます。ピン留めして出したままにもできます。
  • Ctrl + Alt + E

    クイック翻訳

    テキストを選んでショートカットキーを押すと、その場で訳文に置き換わります。
  • Ctrl + Alt + W

    テキスト翻訳

    入力・言語の入れ替え・読み上げに対応した、通常の翻訳ウィンドウです。

このサイトのアプリ画面はすべて繁体字中国語で表示しています。実際の画面は 繁體中文・简体中文・English・日本語・한국어 に切り替えられます。

キャプチャ翻訳

範囲を選ぶと、訳文が原文の上に重なります

ショートカットキーを押して翻訳したい範囲を選ぶだけで、画面の文字を読み取って翻訳します。Web ページ、PDF、画像、漫画、動画、ゲームに対応し、繁体字中国語・簡体字中国語・英語・日本語・韓国語を自動で判別します。

メインウィンドウは閉じてタスクトレイに常駐できるので、ふだんは開いたままにしておく必要はありません。

ツールバーでできること

  • 文字をコピー翻訳せずに、読み取った文字をそのままクリップボードへコピーします。
  • スクリーンショット選んだ範囲をクリップボードへコピーします。設定で「スクリーンショットを保存」を有効にすると画像も保存されます。
  • 注釈ペンツールでキャプチャに直接書き込み、そのままコピーや保存ができます。

リアルタイム翻訳

画面の文字が変われば、訳文もすぐ更新

翻訳したい範囲を選ぶと、画面の文字を読み取り続けて訳文を自動で更新します。動画の字幕、ゲーム画面、マンガに向いており、訳文は元の位置にそのまま表示されます。

2 つの取り込み方法

画面全体、または指定したウィンドウだけを取り込めます。

いつでも一時停止・再開

一時停止すれば、終了せずに原文をそのまま見られます。

動画の字幕、ゲームのストーリー会話、マンガの文字などに適しています。続けて読む文章が中心なら、このモードをお使いください。

ゲームの画面、チャット、メニュー、UI の文字などに適しています。字幕やストーリー会話、マンガの文字でない場合は、このモードをお使いください。

見た目は好みに合わせて調整できます

文字色と背景色は自動と固定のどちらにも設定でき、背景の不透明度、枠線、プレビューも調整できます。

そのほかの翻訳機能

選んでも、入力しても、そのまま翻訳

Ctrl + Alt + Q

テキストを選んでショートカットキーを押すと、そのまま読み込んで翻訳します。何も選んでいないときは直接入力もでき、ピン留めして出したままにもできます。

Ctrl + Alt + E

テキストを選んでショートカットキーを押すと、訳文がそのまま貼り付けられて原文と置き換わります。ウィンドウは開かず、文字を入力できる欄で動作します。

Ctrl + Alt + W

入力または貼り付けたテキストをそのまま翻訳でき、翻訳元と翻訳先の言語はすぐ入れ替えられます。原文と訳文のどちらも読み上げられます。

翻訳サービス

複数の翻訳サービスを内蔵

内蔵の翻訳サービスはインストール後すぐに使えます。アカウント登録も API キーの取得も必要ありません。

  • Microsoft 翻訳

    安定していて応答が速い

    既定

  • Bing 翻訳

    翻訳の品質が良い

    設定不要

  • Google 翻訳

    バランスがよく、ふだん使いに向く

    設定不要

自動フォールバック

ある翻訳サービスが使えない、または応答が遅いときは、使える別のサービスへ自動で切り替わります。やり直したり設定を変えたりする必要はありません。

外部の翻訳サービスと AI モデル

内蔵のサービス以外に、別の翻訳サービスを自分で追加したり、ローカルの AI モデルで翻訳したりできます。どちらも設定しなくてもふだんの利用に支障はありません。

ローカル AI モデルの導入ガイド

プライバシー

画面もデータも手元の PC に留まります

画面の読み取りはローカルで行われ、画像がアップロードされることはありません。翻訳へ送られるのは読み取った文字だけで、ローカルの AI モデルを使えばその工程も手元の PC で完結します。

ログは手元の PC にのみ保存され、自動で送信されることはありません。

1 · 範囲を選ぶ
選んだ範囲はこの PC の中だけにあります。
2 · 文字を読み取る
読み取りもこの PC で行われ、画像は外へ出ません。
3 · 翻訳する
選んだ翻訳サービスへ送られるのは文字だけです。

設定

使い方に合わせて整えられます

  • 表示言語繁体字中国語・簡体字中国語・英語・日本語・韓国語に対応し、切り替えるとすぐに反映されます。初回起動時は Windows の表示言語が自動で適用されます。
  • ショートカットキー組み合わせキー、単一キー、マウスのボタン、ゲームパッドのボタンに対応し、使い方に合わせて設定できます。
  • テーマライトとダークの 2 種類から選べます。
  • 自動翻訳キャプチャの範囲を選んだ時点で翻訳が始まり、ボタンを押す必要はありません。
  • スタートアップとキャプチャの保存Windows の起動時に自動で立ち上げ、キャプチャを指定した場所へ自動保存できます。
