OverTranslate 畫面可見的文字，都能直接翻譯

適用於漫畫、影音與遊戲的 Windows 螢幕翻譯工具，支援截圖翻譯與即時翻譯等多種翻譯功能。

免費下載

翻譯功能

五種翻譯方式，依情境選擇

OverTranslate 提供五種翻譯功能，都能以快捷鍵直接叫出。

  • Ctrl + Alt + A

    截圖翻譯

    框選畫面內容，辨識並將譯文直接顯示在原畫面。
  • 從主視窗啟動

    即時翻譯

    框選影片、遊戲或漫畫的內容，持續辨識並將譯文顯示在原畫面。
  • Ctrl + Alt + Q

    取詞翻譯

    選取文字後開啟精簡翻譯小視窗，也可釘選常駐使用。
  • Ctrl + Alt + E

    快速翻譯

    選取文字後按下快捷鍵，直接翻譯並取代原文。
  • Ctrl + Alt + W

    文字翻譯

    使用完整翻譯視窗，支援文字輸入、語言互換與文字朗讀。

網站中的應用程式畫面統一以繁體中文顯示，實際介面可切換為繁體中文、简体中文、English、日本語、한국어。

截圖翻譯

框選畫面，譯文直接覆蓋原文

按下快捷鍵框選需要翻譯的區域，即可辨識並翻譯畫面文字。支援網頁、PDF、圖片、漫畫、影音與遊戲，並可自動辨識繁體中文、簡體中文、英文、日文與韓文。

主視窗可以直接關閉，程式常駐系統匣，平常不需要一直開著。

工具列還能做這些

  • 複製文字不需翻譯即可將辨識出的文字複製到剪貼簿。
  • 截圖將框選畫面複製到剪貼簿，也可在設定中開啟「儲存截圖」同步存檔。
  • 標記用畫筆工具直接在截圖上標記，再複製或儲存畫面內容。

即時翻譯

畫面文字變動，譯文即時更新

框選翻譯區域後，持續辨識畫面文字並自動更新譯文。適用於影片字幕、遊戲畫面與漫畫閱讀，譯文直接顯示於原位置。

兩種畫面來源

可擷取整個螢幕，或指定單一視窗。

隨時暫停與繼續

暫停時可直接查看原文，不必關閉。

模式

依畫面內容選擇翻譯模式

顯示樣式可依需求調整

文字顏色與底色支援自動或固定設定，並可調整底色透明度、邊框與預覽效果。

取詞翻譯

選取文字，一鍵翻譯

  • 自動帶入選取的文字選取文字後按下快捷鍵，會自動帶入並顯示譯文，不必複製貼上。
  • 沒選取也能直接輸入未選取文字時開啟，可直接輸入想翻譯的內容。
  • 雙語互譯自動判斷輸入的語言，在指定的兩種語言之間互譯，不必手動切換翻譯方向。
  • 釘選後持續顯示釘選後視窗會留在畫面上，方便連續查詢。

其他翻譯功能

快速翻譯

選取文字後按下快捷鍵，翻譯結果會自動貼上並取代原文，無需開啟其他視窗；適用於可輸入文字的欄位。

文字翻譯

輸入或貼上文字即可翻譯，可快速互換來源與目標語言，並支援原文與譯文朗讀。

自動備援

當某個翻譯服務無法使用或回應過慢時，會自動切換到其他可用的服務，不需要自己重試或改設定。

除了內建服務，也能自行加入其他翻譯服務，或使用本地 AI 模型進行翻譯；不額外設定也不影響一般使用。

隱私

畫面與資料皆保留於本機

畫面只在本機辨識，圖片不會上傳。翻譯時僅傳送辨識出的文字；若使用本地 AI 模型，整個流程都能在電腦上完成。

應用紀錄僅儲存在本機，不會自動上傳。

1 · 框選畫面
框選的範圍僅保留在本機。
2 · 辨識文字
文字辨識同樣在本機完成，圖片不會外傳。
3 · 翻譯
僅將辨識出的文字送往所選的翻譯服務。

設定

依使用習慣調整

  • 介面語言支援繁體中文、簡體中文、英文、日文與韓文，切換後立即生效；首次啟動時會依 Windows 顯示語言自動套用。
  • 快捷鍵支援組合鍵、單鍵、滑鼠按鍵與遊戲手把按鍵，可依使用習慣自訂。
  • 主題提供淺色與深色兩種顯示模式。
  • 自動翻譯截圖框選完成後可立即翻譯，無需手動點選按鈕。
  • 開機啟動與截圖儲存可設定開機自動啟動，並自動儲存截圖與指定儲存位置。
