[h2]OverTranslate 2.13.0 更新
[/h2][div][hr][/div][div]完整更新內容可至 GitHub 查看：[/div][div][/div][div][url=https://github.com/Hon-Lu/OverTranslate/releases/tag/2.13.0]https://github.com/Hon-Lu/OverTranslate/releases/tag/2.13.0[/url][/div][div]
[/div][h3]重點摘要
[hr][/h3][div][b]即時翻譯 - 模式改版：[/b]
[ul]
[li]原本的「字幕 / 漫畫」、「遊戲 / 介面」改為三個預設模式：[/li]
[ul]
[li][b]標準：[/b][b][u]依畫面內容自動調整，字幕與介面文字會分別處理，建議優先使用[/u][/b][/li]
[li][b]字幕・漫畫：[/b]適合影片字幕、劇情對話、漫畫對白等連續閱讀的文字[/li]
[li][b]遊戲介面・聊天室：[/b]適合遊戲選單、狀態欄、聊天室等各自獨立的文字[/li]
[/ul][li][b]自訂模式：[/b]可依使用情境自由調整各項辨識與顯示選項，並建立多組不同的設定組合[/li]
[li]翻譯中可直接切換與調整各區塊的模式，不必結束即時翻譯[/li]
[/ul][/div][div][b]即時翻譯 - 新功能與優化：[/b]
[ul]
[li][b]過濾數字與縮寫：[/b]自動過濾畫面上的純數字、符號與 HP、MP 等英文縮寫[/li]
[li]改善靜止畫面上譯文殘留、遊戲選單文字被合併成同一組，以及像素遊戲畫面中英文文字辨識不完整的問題[/li]
[/ul][/div][div][b]設定頁 - 詞彙表：[/b]
[ul]
[li][b]詞彙表：[/b]翻譯時優先使用指定詞彙，讓專有名詞保持一致，(僅支援 AI 翻譯 (本地) 與 OpenAI)[/li]
[/ul][/div][div][b]其他[/b]
[ul]
[li]截圖翻譯也新增[b]「過濾數字與縮寫」[/b]，可在工具列的設定選單開啟[/li]
[li]新增[b]「原文對照」[/b]快捷鍵，快捷鍵也可清除為「未設定」[/li]
[/ul][/div][h3]畫面預覽
